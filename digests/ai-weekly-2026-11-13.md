## This Week's Highlight
**When Evaluators of AI Agents Disagree (arXiv:2611.14581)**
LLM-as-judge is now pervasive in agent evaluation pipelines, but this paper puts a sharp number on how unreliable it is: only 56% agreement with the native benchmark scorer on tau2-bench, and a complete miss on a critical safety violation (forbidden database writes) that a simple rule-based check caught immediately. For practitioners building evaluation pipelines, the takeaway is concrete: LLM judges need hybrid checks — static rule-based boundary validators alongside model-scored dimensions — especially for tasks with hard correctness or safety constraints.
